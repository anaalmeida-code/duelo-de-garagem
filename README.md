# 🏁 Duelo de Garagem

**Projeto de Software — Análise e Desenvolvimento de Sistemas | Faculdade Impacta**

## 🏎️ Sobre o projeto

Duelo de Garagem é um jogo de cartas automotivas inspirado no Super Trunfo, desenvolvido com Python, Flask, SQLite, HTML e CSS.

O objetivo é disputar cinco rodadas contra o computador, comparando características de diferentes veículos para conquistar o maior número de vitórias.

## 🎮 Como funciona

- O jogo possui uma garagem com dez carros.
- Cada rodada apresenta dois veículos sorteados.
- O jogador e o computador alternam a escolha dos atributos.
- O adversário permanece oculto até a comparação.
- Os atributos disponíveis são potência, velocidade máxima e aceleração de 0 a 100 km/h.
- O placar registra vitórias, derrotas e empates.
- Uma barra de progresso acompanha as cinco rodadas.
- Ao final, o jogo apresenta o resultado da partida com animações específicas para vitória, derrota ou empate.

## 💻 Tecnologias utilizadas

- **Python:** lógica do jogo.
- **Flask:** aplicação web e gerenciamento das rodadas.
- **SQLite:** armazenamento dos veículos.
- **HTML:** estrutura das páginas.
- **CSS:** layout responsivo, efeitos visuais e animações.
- **GitHub:** versionamento e organização do projeto.

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Instale o Flask com `pip install flask`.
3. Execute o projeto com `python app.py`.
4. Abra `http://127.0.0.1:5000` no navegador.
5. Clique em **Iniciar Duelo** para começar.

O projeto requer o banco de dados SQLite com a tabela de carros devidamente cadastrada.
